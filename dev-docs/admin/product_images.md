# 商品多图管理

在“商品管理 → 编辑商品 → 商品图片”中，可一次选择多张 JPG、PNG 或 WebP 图片。每个商品最多9张，单张不超过5MB。图片属于商品，同一商品的不同规格共用图库。

上传后可“前移”“后移”调整顺序，或“设为主图”将指定图片移到第一张。删除主图后，下一张自动成为主图。添加、排序和删除都需点击“保存商品”后生效；上传过程中禁止保存，单张上传失败时保留其他成功图片，可重新添加失败文件。

商品列表继续使用第一张主图。小程序与采购网站的商品详情按图库顺序左右滑动，显示当前位置；采购网站另外提供切换按钮和缩略图。点击图片可查看大图。单张图片加载失败不隐藏其他图片。无图商品显示占位提示。

## 数据约定

- 沿用 `Product.images` JSON 数组，不增加迁移。数组顺序就是详情图顺序；`mainImageUrl` 同步为第一项。
- 更新 `images: []` 清空图库及主图；不传图片字段则保留已有图片。
- 旧商品只有 `mainImageUrl` 时，读取接口返回单张图库。旧管理端仅更换 `mainImageUrl` 时，保留其他详情图片。
- 管理标签、真实商品名、商品编码、品牌分类、SKU 和库存不受图库修改影响。
- 删除仅移除商品图片引用，沿用已有对象存储及权限规则，不直接删除共享存储对象。

## 客户端版本

已有小程序详情页已包含多图轮播。后台保存图库后，重新进入详情即可读取多图。v1.2.5 开发包进一步补充点击预览大图和单图加载失败处理，需按微信流程审核发布后覆盖正式客户端。

模拟器与发布包均使用 `https://weiduoxian.cn`，保持线上后端配置。
