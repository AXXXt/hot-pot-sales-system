# 多规格价格、AI库存调整与规格编码

本文记录v1.2.6建立的起步价、单规格库存及编码规则。当前v1.3.0已上线包装换算、批量库存、预占与批次，补充规则见[商品、库存与接单扩展](operations_workflow.md)；包装单位仅按人工配置换算，下文“不换算单位”为v1.2.6历史行为。

## 客户端价格

首页、分类等商品列表对多个启用规格计算最低实际展示价，优先使用当前客户的协议价；价格旁显示“起”和该价格对应的销售单位。单规格不显示“起”，0元协议价仍是有效价格。

最低价规格无货、但其他规格达到起订量时，商品仍可进入详情选择有货规格，不将整件商品标为售罄。详情、进货单和订单继续按实际选定规格计价。

## 一句话调整库存

在后台AI助手输入明确商品、规格和数量，例如：

- 把爆汁牛筋丸500克/袋库存增加10袋。
- 把爆汁牛筋丸500克/袋库存减少3袋，原因是报损。
- 把爆汁牛筋丸500克/袋库存设为30袋。

助手生成“库存调整草稿”，显示商品、规格编码、销售单位及“当前数量 → 调整后数量”。字段修改后先保存以刷新预览，再点击“检查并调整库存”，核对弹窗后“确认执行”。聊天中说“确认”不会直接执行。

重名、多规格或模糊条件需要选择具体SKU；数量单位必须与销售单位一致，不自动将箱换成袋。不能减为负数，也不会为同数量重复创建出入库单。设为0是有效清零操作，仍须核对确认。

需要助手启用、业务写入开启、库存调整能力开启，以及 `ai:use`、`ai:execute`、`inventory:read`、`inventory:adjust` 和对应品牌范围权限。库存能力位于AI配置的业务能力开关中；既有配置缺少这一开关时兼容为开启，全局写入与账号权限继续生效。

确认时重新检查库存、规格资料、权限范围和开关；库存已变化时拒绝旧预览，保存草稿重新核对。确认草稿绑定版本与摘要，10分钟过期；重复或并发确认只执行一次。

执行使用既有库存单据和流水表，出入库单、SKU库存、流水、执行结果及审计在同一事务中保存。失败全部回滚。可在“库存管理”查询，不直接通过普通规格编辑接口修改库存。

## 自动规格编码

“新建规格”中的编码只读，预览已有最大序号的下一项，如 `LIZHIYAN-WanHua-001-01`、`-02` 后新增为 `-03`。保存时由后端锁定商品并分配最终编码，并发新增不会共用编号。

停用规格与旧商品编码下的历史规格也计入序号；不填补空洞，不改动已有规格编码。旧客户端提交的手填编码不参与分配。新规格初始库存仍为0，可通过库存管理或AI确认入库。

本次沿用既有数据库字段和表，不增加迁移，不批量改动商品、SKU或库存。
