## 范围与隔离

网站备案尚未通过，短信仍暂缓。本轮通过本机临时 MySQL 数据库 `weiduoxian_functional_test` 调试订单业务，没有向服务器导入演示客户或订单，也没有修改生产登录机制。

新增 HTTP 集成测试使用真实 JWT 校验、用户状态校验、订单权限守卫、订单服务和 MySQL。测试 JWT 使用随机的本地专用密钥，不能用于服务器登录。审计写入和微信通知使用测试替身，本轮不验证短信、通知送达或外部支付到账。

## 发现与修复

1. 订单及订单明细的租户 ID 写死为 1，导致其他租户创建的订单归属错误，后续查询会受权限守卫拦截。现改为客户实际所属租户。
2. 下单 SKU 查询未限制客户所属租户，其他租户商品可能被提交进订单。现同时限制 SKU 和商品租户，并限制协议价查询租户。
3. 新建订单后另写首条状态日志，日志写入失败可能留下已经创建但返回失败的订单。现使用 Prisma 嵌套创建，与订单和明细一并提交。

回归代码：`backend/test/order-flow.integration-spec.ts`。修复前实际复现了租户不符和跨租户商品返回 201，修复后对应断言通过。

## 已验证

- 下单合并重复 SKU，金额 50.10 x 2 = 100.20。
- 提交、报价、客户确认账期、财务审批、扣库存、发货、收货的完整 HTTP 流程。
- 其他客户、其他租户、没有权限的员工不能查看或修改订单；禁用客户的旧令牌立即失效。
- 下架 SKU 和其他租户 SKU 不能下单。
- 付款凭证必须有当前用户的上传记录；审批、取消不可重复执行，取消后库存恢复。
- 累计退款不能超过应付金额。
- 同单并发账期确认只扣一次额度；不同订单并发确认不会超用客户额度。
- 已完成订单不能再取消或重复收货。
