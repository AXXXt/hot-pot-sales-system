## 腾讯云短信接入

发送接口使用腾讯云短信 API `2021-01-11` 和 TC3-HMAC-SHA256 签名，不依赖客户端 SDK。登录和注册分别使用已审核模板，验证码为六位安全随机数，5 分钟有效；同手机号和同 IP 均限流，连续错误 5 次锁定。

生产 `.env` 需要以下配置，SecretId 和 SecretKey 只能写入服务器 root 可读文件：

```dotenv
SMS_PROVIDER=tencentcloud
TENCENT_SMS_SECRET_ID=
TENCENT_SMS_SECRET_KEY=
TENCENT_SMS_SDK_APP_ID=1401211787
TENCENT_SMS_SIGN_NAME=河南唯哆鲜食品有限公司
TENCENT_SMS_LOGIN_TEMPLATE_ID=2746507
TENCENT_SMS_REGISTER_TEMPLATE_ID=2746506
TENCENT_SMS_REGION=ap-guangzhou
```

SecretId 和 SecretKey 应来自仅授予短信发送权限的 CAM 子用户，不得使用腾讯云主账号密钥，不得提交到 Git、聊天记录、小程序或浏览器。发布顺序为：备份生产环境、构建并导入新后端镜像、更新 `.env`、迁移（本次无新迁移）、重建 backend、重载 Nginx。未完成镜像发布前直接改 `SMS_PROVIDER=tencentcloud` 会因镜像不含发送适配器而不可用。

发布后先用一个内部手机号验证：登录验证码能收到、模板参数显示 5 分钟、错误验证码被拒绝、连续发送返回 429、错误 5 次锁定、注册申请使用注册模板。验证通过后再关闭体验验证码。
